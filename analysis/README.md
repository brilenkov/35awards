# VLM-разборы

`analysis/analyses.json` — ручные/VLM-разборы фотографий с точки зрения профессионального фотографа. Ключ — `photo_id` из 35AWARDS.

Pipeline читает файл при каждом запуске и добавляет в `data.json` поля `analysis` и `facets`. Если для фото разбора нет, оно всё равно попадает в каталог, но без блока «Разбор фотографа».

## Фасеты для фильтров

Допустимые значения заданы в `config/facets.json`. Группы:

- `light` — свет;
- `color` — цвет / ч-б / температура / насыщенность;
- `technique` — техника съёмки;
- `image` — образ;
- `emotion` — эмоция;
- `season` — сезон;
- `focal` — фокусное расстояние.

В фасетах можно указывать несколько значений. Фильтр на сайте проверяет вхождение выбранного значения в массив.

## Важно

Фокусное расстояние, диафрагма и схема света определены по изображению и являются **экспертной оценкой**, а не EXIF. В карточке сайта это указано. Точные параметры съёмки знает только автор.

Базовые `color`-фасеты (`bw`, `monochrome`, `color`) дополнительно считаются автоматически по насыщенности пикселей для всех работ. Это не заменяет VLM-разбор: тёплый/холодный, свет, эмоции и жанр появляются только после ручной/VLM-разметки.

## Схемы света: договорённость

Чтобы фильтр не путал близкие схемы:

- `rembrandt` — на теневой стороне щеки под глазом читается выраженный световой треугольник.
- `loop` — под носом небольшая тень-петля, треугольника на щеке нет.
- `split` — одна половина лица освещена, вторая уходит в тень.
- `backlight` — источник за моделью, работает контур/ореол; он может быть мягким (rim light) или жёстким (силуэт).
- `window` — свет из окна, обычно мягкий и направленный.
- `low-key` — общий низкий ключ, тёмный фон и глубокие тени.
- `soft` / `hard` — характеристика источника, а не схема.

## Образ: `documentary`

`documentary` — только для кадров, где человек снят в естественном, непостановочном контексте: репортаж, улица, наблюдение. Если это постановочный или студийный портрет с реальным человеком, лучше `character` / `fine-art` / `staged`, но не `documentary`.

Если схема спорная, лучше выбрать более общий тег (`soft`, `studio`) и не добавлять `rembrandt` «на всякий случай».
